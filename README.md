# Решение задачи Авито Антибот

Python 3.10.12. Используются локальные open-source библиотеки NumPy, pandas и scikit-learn; внешние API и языковые модели не используются. `random_state=42`.

```bash
python3.10 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

`solution.ipynb` читает `data/train.csv`, `data/test.csv` и `data/events.csv.gz`, берёт только события в полуоткрытом суточном окне `[window_start_ts, window_end_ts)` и строит 100 признаков на строку наблюдения: число и доли действий, разнообразие объявлений и запросов, глубину поиска, интервалы (включая среднее и разброс пауз до 5 минут) и переходы между событиями, координаты курсора, платформу и признаки User-Agent. 
Идентификаторы cookie и объявлений не используются как признаки. Оценка это взвешенное среднее (75% и 25%) прогнозов двух моделей `HistGradientBoostingClassifier` из scikit-learn. 
Итоговый файл — `submission.csv` с колонками `cookie_id,score`.
