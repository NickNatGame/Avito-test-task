# Решение задачи Авито Антибот

Python 3.10.12. Используются локальные open-source библиотеки NumPy, pandas и scikit-learn; внешние API и языковые модели не используются. `random_state=42`.

```bash
python3.10 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python test_solve.py
.venv/bin/python solve.py
```

`solve.py` читает `data/train.csv`, `data/test.csv` и `data/events.csv.gz`, берёт только события в полуоткрытом суточном окне `[window_start_ts, window_end_ts)` и строит 98 признаков на cookie: число и доли действий, разнообразие объявлений и запросов, глубину поиска, интервалы и переходы между событиями, координаты курсора, платформу и признаки User-Agent. Идентификаторы cookie и объявлений не используются как признаки. Модель — `HistGradientBoostingClassifier` из scikit-learn. Итоговый файл — `submission.csv` с колонками `cookie_id,score`.

`solution.ipynb` содержит тот же код с пояснениями по шагам; откройте его из корня проекта и выполните все ячейки по порядку.

Проверка по будущим датам внутри обучающей выборки официальной функцией `metric.precision_at_recall`:

| Обучение | Проверка | Precision при Recall ≥ 70% | PR-AUC | ROC-AUC |
|---|---|---:|---:|---:|
| 06–13 апреля | 14–16 апреля | 0.7366 | 0.7642 | 0.9306 |
| 06–16 апреля | 17–19 апреля | 0.7847 | 0.7818 | 0.9339 |

После проверки модель обучается на всём `train.csv` и создаёт по одной оценке для каждой cookie из `test.csv`. Метрики теста неизвестны; указанные результаты относятся только к локальной проверке.
